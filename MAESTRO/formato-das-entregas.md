# Formato das entregas

> Como o dono gosta de receber cada tipo de coisa. Cresce conforme ele aprova ou corrige formatos.

## No chat

**Tabela para comparação.** Mais de 2 itens com os mesmos atributos: tabela vence lista.

**Veredito por linha.** Numa tabela de decisão, cada linha termina com a conclusão ("vivo", "morto",
"metade"), não só com o dado bruto.

**Negrito no que decide.** O achado que muda a decisão fica em negrito; o resto é contexto.

**Texto que ele vai usar vem no chat, pronto para copiar.** Mensagem para cliente, prompt, legenda,
roteiro: cada texto num bloco próprio, um por destinatário ou uso, sem nada dentro do bloco além do que
ele cola. Nunca guardado num arquivo para ele abrir.

**Caminho clicável** ao citar arquivo do repositório.

## Página HTML

Para o que ele vai revisar com calma, apresentar a terceiro ou consultar depois: página HTML, não texto
no chat (aprovação de peça, plano navegável, proposta, painel). Publicada num endereço real, a página
hospedada vira a fonte única: nunca manter uma cópia em paralelo para editar.

## Prova visual para aprovar

Print ou prova de tela vai numa pasta, com o caminho clicável no chat. Tela de sistema se aprova no modelo
real aberto no navegador dele, com a pergunta na conversa ativa.

## O que nunca vem sozinho

Número sem período de referência · conclusão sem racional · proposta sem o custo · risco sem o tamanho
dele.
